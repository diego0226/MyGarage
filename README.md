# MyGarage Web

**MyGarage** es una aplicación web diseñada para simular la gestión de un garaje o taller automotriz. La plataforma permite a los usuarios interactuar con un sistema pensado para la administración de vehículos, servicios y mantenimiento, ofreciendo una interfaz moderna y fácil de utilizar.

El objetivo del proyecto es demostrar el desarrollo de una aplicación web enfocada en la organización y visualización de información relacionada con vehículos y servicios automotrices, aplicando buenas prácticas de desarrollo frontend y despliegue en la web.

## Características

- Interfaz moderna y responsiva.
- Navegación sencilla entre las diferentes secciones del sistema.
- Organización de información relacionada con vehículos y servicios.

## Instalación y Uso

Si deseas ejecutar el proyecto de forma local:

### 1. Clonar el repositorio

```
git clone https://github.com/tu-usuario/mygarage.git
```

### 2. Entrar a la carpeta del proyecto

```
cd mygarage
```

### 3. Instalar dependencias

```
npm install
```

### 4. Ejecutar el proyecto

```
npm run dev
```

La aplicación se abrirá en:

```
http://localhost:5173
```
